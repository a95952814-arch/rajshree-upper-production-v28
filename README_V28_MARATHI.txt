Rajshree Shoes Android Project — Version 28

या ZIP मध्ये Android प्रोजेक्ट आहे; APK फाइल नाही.
PC Version 28 चा index.html Android WebView मध्ये वापरला आहे.
Android versionCode 28 आणि versionName 2.8 केले आहे.

APK तयार करण्यासाठी:
1. ZIP Extract All करा.
2. GitHub repository a95952814-arch/rajshree-upper-production मध्ये प्रोजेक्टमधील फाइल्स अपडेट करा.
3. app/src/main/assets/index.html हा नवीन V28 HTML असावा.
4. GitHub Actions → Build Rajshree Shoes APK → Run workflow.
5. Green successful run झाल्यावर Summary → Artifacts → rajshree-shoes-apk डाउनलोड करा.
6. Artifact ZIP Extract केल्यावर app-debug.apk मिळेल.

महत्त्वाचे: APK येथे build करून device वर तपासलेला नाही. मोबाईलवर install केल्यानंतर data, Edit/Save आणि WhatsApp तपासा.
